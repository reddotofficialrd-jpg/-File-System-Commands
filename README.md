## 📋 Lab Questions

Here are the questions to answer for this lab:

1. What is the name of the file located inside the `"loot"` folder?
2. What are the contents of the file that was in the `"loot"` folder?
3. What are the contents of the hidden file in the `"loot"` folder?

---

## 🚀 Objective
Perform basic file system commands on the target machine via SSH to locate and retrieve the required flags.
